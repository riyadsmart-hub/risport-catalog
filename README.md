# كتالوج ري سبورت

ملف `catalog.json` يُولَّد تلقائياً كل ساعة من **واجهة المتجر العامة** لـ
[risport-sa.com](https://risport-sa.com) — نفس البيانات المنشورة على صفحات المتجر
(أسماء · أسعار · صور · مقاسات · ألوان). لا يحوي أي بيانات تكلفة أو موردين أو أسرار.

يقرأه تطبيق ري سبورت للجوال عند كل فتح، فيتحدّث السعر والمنتجات **بلا إصدار تطبيق جديد**.

## التوليد يدوياً

```bash
CATALOG_OUT=catalog.json node scripts/sync-catalog.mjs
```

لا يحتاج أي مفتاح أو صلاحية — ترويسة `Store-Identifier` وحدها، وهي منشورة
في HTML المتجر العام.
